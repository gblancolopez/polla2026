🔧 Configurar base de datos compartida

¿Por qué necesitas esto?
Sin esto, los datos solo existen en tu dispositivo. Con esto, cada participante puede abrir la app en su celular y todos ven los mismos pronósticos y puntuaciones.
El administrador hace esto una sola vez:
1
Abre script.google.com con tu cuenta de Google. Haz clic en el botón azul "Nuevo proyecto".
2
Borra el código que aparece y pega este (también puedes usar el botón copiar):
// POLLA MUNDIAL 2026 - Base de datos
const CLAVE = 'polla2026_v1';

function doGet(e) {
  const props = PropertiesService.getScriptProperties();
  const raw = props.getProperty(CLAVE);
  const data = raw ? JSON.parse(raw) : initData();
  return ContentService
    .createTextOutput(JSON.stringify({ok:true, data}))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    const body = JSON.parse(e.postData.contents);
    if (body.action === 'setData') {
      PropertiesService.getScriptProperties()
        .setProperty(CLAVE, JSON.stringify(body.data));
      return ContentService
        .createTextOutput(JSON.stringify({ok:true}))
        .setMimeType(ContentService.MimeType.JSON);
    }
  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({ok:false}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function initData() {
  return {participantes:[], pronosticos:{},
          resultados:{}, adminPass:'admin2026'};
}
3
Haz clic en el botón "Implementar" (ícono de nube con flecha arriba a la derecha) → "Nueva implementación".
  • En "Tipo" selecciona "Aplicación web"
  • En "Ejecutar como" elige "Yo (tu email de Google)"
  • En "Quién tiene acceso" elige "Cualquier persona"
  • Haz clic en "Implementar" y acepta los permisos que pide
4
Google mostrará una "URL de la aplicación web". Se ve así:
